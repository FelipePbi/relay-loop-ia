# synthetic-001 — Tarefa sintética do IA Loop

Esta tarefa **não pertence ao runtime do Atendly**. Ela existe apenas para
exercitar o caminho Developer → Reviewer da Vertical Slice V1.

O objetivo não é medir capacidade de programação. É provar o transporte:
resultado estruturado do Developer virando input estruturado do Reviewer.

## Tarefa

Considere uma função `sum(a, b)` que recebe dois números e retorna a soma.

Raciocine sobre ela mentalmente:

- qual é o comportamento esperado para dois inteiros positivos;
- qual é o comportamento esperado quando um dos argumentos é zero;
- que tipo de entrada tornaria o resultado inválido.
